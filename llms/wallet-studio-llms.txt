# Wallet Studio

> Wallet Studio, by Miss Moneypenny Technologies GmbH, is a no-code SaaS platform for building, deploying, and managing Apple Wallet and Google Wallet passes. It targets insurance carriers, turning policy admin, claims, and CRM systems into wallet-based customer engagement channels. The platform exposes a REST API and webhooks for integration; there is no public developer portal, API reference, or OpenAPI specification (the REST API is provisioned per customer).

## Integration surface

- Webhooks: advertised for real-time wallet event connectivity into automation systems.

## Notes
- No public /.well-known discovery documents (security.txt, openid-configuration, oauth-authorization-server, api-catalog, ai-plugin.json all return 404).
- No first-party SDKs or client libraries; the GitHub organization contains only upstream forks.
